# ЧТЗ (упрощённое): Панели Яндекс.Вебмастера в Grafana

## Проблема
Метрики monitoring_search_* собираются, но в дашбордах Grafana нет ни одной панели с ними.

## Изменения
1 файл: `grafana/dashboards/site-overview.json` — новая секция «Поиск (Яндекс.Вебмастер)»:
- Stat: Всего кликов за неделю — `sum(monitoring_search_clicks_total{site="$site"})`
- Stat: Всего показов за неделю — `sum(monitoring_search_shows_total{site="$site"})`
- Table: Топ-15 запросов по кликам — `topk(15, monitoring_search_clicks_total{site="$site"})` (колонки: Запрос, Клики)
- Timeseries: Средняя и лучшая позиция — `avg(...)` / `min(monitoring_search_position{site="$site"})`, invert Y (меньше = лучше)

## Критерии приёмки
1. Панели появляются на дашборде site-overview (uid: site-overview) после пересборки
2. Переменная $site фильтрует все новые панели
3. Данные видны после первого цикла сбора webmaster (раз в час)
4. JSON валиден, остальные панели не затронуты

## Маршрутизация
Аналитик → Разработчик → Тестировщик → DevOps
