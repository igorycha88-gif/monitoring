# ЧТЗ: Единый дашборд Вебмастера (одна страница + переключатель сайта)

- Дата: 2026-08-19
- Источник: запрос пользователя («все дашборды по Вебмастеру на одной странице,
  переключатель по выбору сайта»)
- Маршрут: Аналитик → **Разработчик → Тестировщик → DevOps**
- Основание: `требования/ADR-008_Дашборды_Вебмастера_динамика_и_топы.md`

## 1. Цель

Заменить два отдельных дашборда Вебмастера (`webmaster-dynamics`,
`webmaster-top-queries`) одним единым дашбордом, где все панели Вебмастера
размещены на одной странице, а статистика переключается выбором сайта в
единственной переменной `site` (подтверждено пользователем: старые дашборды
удалить).

## 2. Что делаем

### TASK-FRT-1: Единый дашборд `grafana/dashboards/webmaster.json`

- uid: `webmaster`, title: «Вебмастер: поиск по сайту», tags: `webmaster`,
  `search`.
- Переменные:
  - `site` — query, `label_values(monitoring_search_clicks_total, site)`,
    single choice (multi=false, includeAll=false), label «Сайт» —
    единый переключатель сайта для ВСЕХ панелей;
  - `period` — custom: Неделя=7d, Месяц=30d, Год=365d (для таблиц топов).
- Панели (все на одной странице, layout):
  - y=0: «Показы по дням» (timeseries, w=12 h=10) —
    `sum(monitoring_search_daily_shows{site="$site"})`;
  - y=0 (x=12): «Клики по дням» (timeseries, w=12 h=10) —
    `sum(monitoring_search_daily_clicks{site="$site"})`;
  - y=10: «Топ-5 запросов по позиции (лучшие)» (table, instant, w=8 h=10) —
    `bottomk(5, avg_over_time(monitoring_search_position{site="$site"}[$period]))`;
  - y=10 (x=8): «Топ-5 запросов по кликам» (table, instant, w=8 h=10) —
    `topk(5, avg_over_time(monitoring_search_clicks_total{site="$site"}[$period]))`;
  - y=10 (x=16): «Топ-5 запросов по показам» (table, instant, w=8 h=10) —
    `topk(5, avg_over_time(monitoring_search_shows_total{site="$site"}[$period]))`.
- Содержимое панелей (fieldConfig, overrides, transformations, переименования
  колонок «Запрос»/«Средняя позиция»/«Клики-Показы/нед (среднее за период)»)
  переносится из старых дашбордов без изменений.
- `time`: `now-30d` → `now` (динамика по дням — основной срез; таблицы —
  instant и от time не зависят).
- description: объединённое из двух старых (динамика = сумма по
  отслеживаемым запросам топа — приближение к полному сайту, обновление раз в
  сутки ~07:00 MSK с лагом ~1 день; срезы месяц/год таблиц — приближение из
  накопленных недельных снапшотов).

### TASK-FRT-2: Удаление старых дашбордов

- Удалить `grafana/dashboards/webmaster-dynamics.json` и
  `grafana/dashboards/webmaster-top-queries.json`.
- Provisioning (`grafana/provisioning/dashboards/dashboards.yml`,
  `disableDeletion: false`, `updateIntervalSeconds: 30`) подхватит удаление
  автоматически — отдельная чистка БД Grafana не требуется.

### TASK-TST-1: Обновление автотестов

- `tests/test_dashboards.py`:
  - `DASHBOARD_NAMES`: `webmaster-dynamics.json` и `webmaster-top-queries.json`
    → `webmaster.json`;
  - `test_webmaster_dynamics_structure` и `test_webmaster_top_queries_structure`
    заменить на `test_webmaster_unified_structure`: 5 панелей, uid `webmaster`,
    единая переменная `site` (multi=false, includeAll=false, label_values по
    `monitoring_search_clicks_total`), переменная `period` (7d/30d/365d),
    expr-проверки всех 5 панелей, пометка «приближение» в description.
  - Общие тесты (валидность JSON, известные метрики, фильтр `site="$site"`,
    отсутствие rate/increase/sum_over_time на monitoring_*, пороги по
    возрастанию, datasource prometheus) продолжают действовать.

## 3. Ограничения

- Новые метрики/коллекторы/API НЕ добавляются — только Grafana JSON + тесты.
- Все expr используют фильтр `site="$site"` (регламент проекта).
- Данные и их приближённость — как в ADR-008, без изменений логики запросов.

## 4. Критерии приёмки

1. В `grafana/dashboards/` ровно один дашборд Вебмастера: `webmaster.json`
   (uid `webmaster`); файлы `webmaster-dynamics.json`,
   `webmaster-top-queries.json` удалены.
2. Все 5 панелей Вебмастера размещены на одной странице дашборда.
3. Переключатель «Сайт» (переменная `site`) фильтрует ВСЕ панели; смена сайта
   меняет отображаемую статистику.
4. Переключатель «Период» влияет на таблицы топов (7d/30d/365d).
5. `pytest && ruff check . && mypy .` — зелёные, включая обновлённые тесты
   дашбордов.
6. После деплоя единый дашборд виден в Grafana, старые — отсутствуют.
