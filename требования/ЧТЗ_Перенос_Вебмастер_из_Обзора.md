# ЧТЗ: Перенос метрик Вебмастера из «Обзор сайта» в единый дашборд Вебмастера

- Дата: 2026-08-19
- Источник: запрос пользователя («со вкладки Обзор сайта перенеси все метрики
  по Вебмастеру»)
- Маршрут: Аналитик → **Разработчик → Тестировщик → DevOps**
- Основание: `требования/ЧТЗ_Дашборд_Вебмастер_Единый.md` (продолжение
  консолидации), ADR-004/ADR-008 (метрики Вебмастера)

## 1. Цель

Все панели Вебмастера проекта — только в едином дашборде
«Вебмастер: поиск по сайту» (`webmaster.json`). Из «Обзора сайта»
(`site-overview.json`) секция Вебмастера удаляется и переносится в
`webmaster.json` без изменения запросов.

## 2. Что переносим (конфигурации панелей сохраняются как есть)

Из `site-overview.json` (панели с id 100–105) в `webmaster.json`:

1. Row «Поиск (Яндекс.Вебмастер, за последнюю неделю)» → row с тем же
   названием (секция в единый дашборд);
2. stat «Клики за неделю» — `sum(monitoring_search_clicks_total{site="$site"})`;
3. stat «Показы за неделю» — `sum(monitoring_search_shows_total{site="$site"})`;
4. text-панель (справка о данных: топ-50 запросов за последнюю неделю,
   обновление раз в час);
5. table «Топ-15 поисковых запросов по кликам» (instant) —
   `topk(15, monitoring_search_clicks_total{site="$site"})`;
6. timeseries «Позиция в поиске (меньше — лучше)» —
   `avg(monitoring_search_position{site="$site"})` +
   `min(monitoring_search_position{site="$site"})`.

### Layout `webmaster.json` после переноса

- y=0: «Показы по дням» (w=12 h=10), «Клики по дням» (w=12 h=10);
- y=10: «Топ-5 по позиции» (w=8), «Топ-5 по кликам» (w=8), «Топ-5 по показам» (w=8);
- y=20: row «Поиск (Яндекс.Вебмастер, за последнюю неделю)» (w=24 h=1);
- y=21: «Клики за неделю» (stat w=6 h=5), «Показы за неделю» (stat w=6 h=5),
  text-справка (w=12 h=5);
- y=26: «Топ-15 поисковых запросов по кликам» (table w=12 h=10),
  «Позиция в поиске (меньше — лучше)» (timeseries w=12 h=10).

## 3. Ограничения

- Запросы (expr) и конфигурации панелей переносятся БЕЗ изменений.
- Новых метрик/коллекторов/API нет.
- Все expr с фильтром `site="$site"` (регламент проекта).

## 4. Критерии приёмки

1. `webmaster.json` содержит 10 панелей (5 прежних + row + 2 stat + text +
   таблица топ-15 + позиция), layout без перекрытий.
2. `site-overview.json` содержит 13 панелей, метрики `monitoring_search_*`
   в нём отсутствуют.
3. Переключатель «Сайт» фильтрует все перенесённые панели.
4. `pytest && ruff check . && mypy .` — зелёные.
5. После деплоя: обе вкладки в Grafana обновлены, Вебмастер — только в
   едином дашборде.
