## 3. Диагноз и стратегия

### 3.1. Почему 0 кликов

1. Позиции 7–15 = вторая страница → CTR ≈ 0%.
2. Нет гео-страниц → сайт не участвует в самом большом кластере спроса: «забор из профнастила в Балашихе», «навес для машины в Раменском» и т.п. Пользователи в МО почти всегда пишут город в запросе.

## 4. Требования к гео-посадочным страницам (анти-дорвей)

Главная ошибка конкурентов — генерить «тощие» дорвеи «Забор в {город}» с одним абзацем. Яндекс такие страницы пессоризирует. Наши страницы обязаны иметь **реальную локальную ценность**.

### 4.1. Структура URL

```
/zabory-navesy/{gorod}/          ← главная гео-страница города
   /zabory-navesy/balashiha/
   /zabory-navesy/lyubercy/
   /zabory-navesy/podolsk/       ...
```
Не плодить матрицу «услуга×город» (6 услуг × 20 городов = 120 дублей). Одна богатая страница на город, услуги внутри секциями с ссылками на /services/*.

### 4.2. Шаблон страницы города (обязательные блоки)

| Блок | Требования |
|---|---|
| **Title** | `Заборы и навесы в {Городе} под ключ — цена от 2 600 ₽/м | Монтаж за 1 день` (≤ 65 симв.) |
| **Description** | `Заборы из профнастила и евроштакетника, навесы для авто в {Городе} и {Районе}. Замер бесплатно, монтаж от 1 дня, гарантия 2 года. Тел: +7 (499) 390-15-95` |
| **H1** | `Заборы и навесы в {Городе}` |
| H2-секции | `Забор из профнастила в {Городе}` · `Евроштакетник и 3D-заборы` · `Навесы для автомобилей в {Городе}` · `Цены с монтажом и доставкой` · `Наши объекты в {Городе} и районе` · `Районы выезда` · FAQ |
| **Локальная привязка** (критично!) | реальное мин. 30% уникального текста: расстояние/время выезда бригады, знание местных реалий (напр. «в старом центре Орехово-Зуева участки узкие — ставим заборы с монтажом «в stretку» без заезда техники»), выполненные объекты с фото из этого города/района, отзывы клиентов из города |
| **Районы выезда** | микрорайоны и окрестные поселки (для Балашихи: Железнодорожный, Купавна, Ольгино…; для Раменского: Кратово, Ильинский, Быково…) — это отдельные низкочастотные ключи |
| **Цены** | таблица «сколько стоит забор в {Городе}» с учётом логистики из базы; калькулятор |
| **FAQ** (5–7 вопросов) | «Сколько стоит забор из профнастила в {Городе} за метр под ключ?», «Выезжаете ли в {посёлки района}?», «За сколько дней установите забор в {Городе}?», «Работаете ли зимой?» + микроразметка FAQPage |
| **Schema.org** | `LocalBusiness` + `areaServed` (город + район), `Service`, `FAQPage`, `BreadcrumbList` |

### 4.3. Перелинковка (обязательная схема)

```
Главная ── блок «Города» (заменить Мытищи!) ──→ все гео-страницы
Гео-страница города ──→ /services/* (6 услуг) ──→ калькулятор
Гео-страница города ──→ соседние города того же направления (восток↔восток)
Статьи блога ──→ гео-страницы («Заказать навес в Балашихе»)
Хаб направления ──→ все города направления
```

### 4.4. Семантическое ядро гео-страницы (шаблон сбора)

На каждый город — кластер:

- забор из профнастила в {городе} / забор под ключ {город} / установить забор {город}
- забор на дачу {город} / {район} (для дачных направлений)
- евроштакетник {город} / забор шахматка {город}
- навес для машины {город} / навес во двор {город} / навес из поликарбоната {город}
- купить забор {город} / цена забора {город} / забор за метр {город}
- откатные ворота {город} / ворота с калиткой {город}
- сетка рабица {город} / 3d забор {город}

Частотность проверить через Wordstat (оператор `"город"`), но даже при НЧ 10–30/мес сумма 20 городов × 10 запросов = ощутимый поток с конверсией 5–15% (горячий гео-спрос).
