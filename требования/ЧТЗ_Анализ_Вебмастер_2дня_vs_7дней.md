# ЧТЗ: Анализ Вебмастера — последние 2 дня vs предыдущие 7 дней (3 сайта)

> Дата: 27.08.2026 · Маршрут: малая задача (раздел 6 AGENTS.md) — разовая аналитика, без изменений кода/метрик/API/дашбордов.
> Роль: 📋 Аналитик → 💻 Разработчик (локальный backfill + SQL-отчёт) → 🧪 Тестировщик (сверка цифр) → без DevOps (деплой не нужен).
> Образец формата: `требования/Анализ_Вебмастер_3_сайта_22-23_августа.md`.

## 1. Постановка

Пользователь изменил SEO-оптимизацию на сайтах и хочет понять, виден ли эффект в
статистике Яндекс.Вебмастера за последние 2 завершённых дня по сравнению с
предыдущими 7 завершёнными днями.

## 2. Параметры (ответы пользователя)

- **Сайты:** все 3 — `da-dryclean.ru`, `эвакуация.online`, `zabor-i-naves.ru`.
- **Дата SEO-оптимизации:** неизвестна («недавно») → граница «до/после» = последние 2 завершённых дня.
- **Сравнение:** 2 завершённых дня («после») vs предыдущие 7 завершённых дней («до»).

## 3. Период

Сегодня (по UTC): 2026-08-27 15:22 ≡ 2026-08-27 18:22 по Москве. Завершённые дни
Вебмастера (исключая сегодняшний незавершённый):

- **«После» (последние 2 завершённых дня):** 2026-08-25, 2026-08-26.
- **«До» (предыдущие 7 завершённых дней):** 2026-08-18 … 2026-08-24.

Окно backfill: 31 день (полное окно API Вебмастера) — покроет и «до», и «после», и
более ранний baseline при необходимости.

## 4. Исполнитель и этапы

1. **Backfill** `data/webmaster.db` через `scripts/backfill_webmaster_daily.py`
   с `WEBMASTER_HISTORY_DAYS=31` — заполнит `webmaster_daily` и `webmaster_weekly`
   для всех 3 сайтов. Запуск локально через `.venv` (без docker, порт-конфликтов
   нет, существующее приложение не затрагивается — раздел 0.1).
2. **SQL-анализ** прямо по SQLite: суммы показов/кликов по сайту за 2 дня и 7 дней,
   средние позиции, топ-запросы с динамикой, расчёт CTR и дельт в %.
3. **Отчёт** в `требования/Анализ_Вебмастер_2дня_vs_7дней_2026-08-27.md` по образцу.

## 5. Критерии приёмки

- [ ] БД `data/webmaster.db` содержит `webmaster_daily` для всех 3 сайтов за период
      не короче 2026-08-18 … 2026-08-26 (минимум 9 завершённых дней).
- [ ] `webmaster_weekly` содержит свежий снапшот (`fetched_at` ≈ сейчас) по каждому
      из 3 сайтов с позициями запросов.
- [ ] В отчёте для каждого сайта есть:
  - суммы показов и кликов за «после» (2 дня) и «до» (7 дней);
  - дельты в %;
  - среднесуточные значения (чтобы 2 дня были сопоставимы с 7 днями);
  - CTR за оба периода;
  - топ-7 запросов с динамикой позиций и показов;
  - вывод о наличии/отсутствии эффекта SEO-оптимизации.
- [ ] Цифры в отчёте сверяются с SQL-запросами — Тестировщик повторяет запросы.
- [ ] Секреты (токены) не попадают в отчёт и в логи.
