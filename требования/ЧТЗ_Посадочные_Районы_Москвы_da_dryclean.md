## 1. Цель

Создать систему гео-посадочных страниц под все районы и округа Москвы для захвата
локального спроса «химчистка мебели + район» и усиления региональной релевантности
сайта в Яндексе по Москве.

**KPI (6 месяцев после полного запуска):**
- Трафик из поиска: с ~5 кликов/нед → 150+ кликов/нед (контроль: Grafana, дашборд
  Webmaster, метрики `monitoring_search_daily_clicks`).
- Индексация: ≥ 90% гео-страниц в индексе Яндекса (по «Страницы в поиске» Вебмастера).
- Отсутствие санкций Яндекса за doorway (контроль: позиции бренда + ядра).

## 2. Объём и структура

**Всего 137 гео-страниц:**

| Уровень | Кол-во | Примеры |
|---|---|---|
| Административные округа | 12 | ЦАО, САО, СВАО, ВАО, ЮВАО, ЮАО, ЮЗАО, ЗАО, СЗАО, ЗелАО, НАО, ТиНАО |
| Районы | 125 | Бибирево, Митино, Отрадное, Марьино, Митино, Кунцево, Орехово-Борисово… |

Поселения Новой Москвы (21 шт.) и Зеленоград — **этап 2**, после успешного этапа 1
(критерии приёмки этапа 1 см. §8).

### 2.1. URL-структура (плоская, ЧПУ, кириллица не используется)

```
/himchistka-mebeli/                    — хаб услуги (существует/усиливается)
/himchistka-mebeli/moskva/svao/        — хаб округа (12 шт.)
/himchistka-mebeli/moskva/svao/bibirevo/ — страница района (125 шт.)
```

Транслитерация районов — по официальным правилам (bibirevo, orehovo-borisovo,
maryino). Один район — один URL, без дублей и параметров.

### 2.2. Принцип «одна страница — одна сущность»

Страница района содержит ВСЕ услуги (диваны, матрасы, ковры, мягкая/кожаная мебель)
секциями с анкорами — **не** порождаем 125×5=625 страниц услуг-районов (прямая
дорога под doorway-фильтр).

## 3. Требования к контенту (АНТИ-DOORWAY, критично)

Яндекс фильтрует шаблонные гео-страницы без пользы для пользователя. Каждая страница
района обязана содержать **реальную ценность**, а не подстановку района в шаблон.

### 3.1. Уникальный блок (≥ 40% контента страницы, пишет копирайтер)

- Связь с районом: время подачи мастера (реальное, из логистики),
  ближайшие метро/МЦК/МЦД с временем в пути.
- Локальные особенности застройки: панельные/кирпичные/новостройки, габариты лифтов
  (влияет на вынос мебели), характерные интерьеры.
- 2–3 отзыва клиентов ИЗ ЭТОГО района (имя, дата, фото «до/после»).
- Ссылки на соседние районы (перелинковка) и на хаб округа.

### 3.2. Обязательные шаблонные блоки (полезные, не «вода»)

- Блок стоимости: заметная ссылка на прикреплённый прайс-лист + кнопка/форма
  «Запросить стоимость у менеджера» (расчёт за 15 мин). Табличные цены на странице
  НЕ размещаются (ценовая политика v1.1).
- Форма заявки с авто-подстановкой района.
- Карта района (Яндекс.Карты, статичная — без JS-зависимости).
- FAQ (5–7 вопросов, уникализированные 2 ответа под район; вопросы про стоимость
  закрываются отсылкой к прайсу/менеджеру — без публикации цифр).
- Блок «Как мы работаем» (этапы).

### 3.3. Мета-теги (шаблон + уникализация, БЕЗ цен)

- **Title:** `Химчистка мебели в районе Бибирево — мастер за 60 мин, расчёт стоимости за 15 мин | MOS Dry Cleaning`
- **Description:** `Чистка диванов, матрасов и ковров на дому в Бибирево. Мастер приедет за 60 минут. Прайс-лист на сайте, расчёт у менеджера, онлайн-заявка.`
- H1: `Химчистка мебели на дому в районе Бибирево`
- В Title/Description подставляются: реальное время подачи района. Цены не указываются.

### 3.4. Разметка

- `LocalBusiness` + `areaServed` (GeoShape/район), `Service` (без `Offer` с ценой —
  цены не публикуются), `AggregateRating`, `FAQPage`, хлебные крошки `BreadcrumbList`.

## 4. Технические требования

1. `sitemap.xml` — отдельный блок гео-страниц, lastmod реальные.
2. Хлебные крошки: Главная → Услуга → Округ → Район (видимые + разметка).
3. Скорость: LCP < 2.5 c, страницы серверные (SSR/статика), без тяжёлых JS.
4. `robots.txt` не закрывает гео-страницы; canonical сам на себя.
5. Мобильная версия = десктоп по контенту.
6. Пагинации нет; фильтров нет.

## 5. Этапы запуска (обязательная поэтапность)

| Этап | Объём | Условие перехода |
|---|---|---|
| 1. Пилот | 12 округов + 15 крупнейших районов (Бибирево, Митино, Марьино, Отрадное, Кунцево, Строгино, Химкинский… — по населению) | Индексация ≥ 90%, рост показов по гео-запросам через 4 нед, нет санкций |
| 2. Основной массив | +55 районов (70 суммарно) | Те же критерии |
| 3. Полное покрытие | +55 районов (125 суммарно) | Те же критерии |
| 4. (Опция) | Поселения НМАО/ТиНАО/Зеленоград | Отдельное решение |

Мониторинг эффекта — по нашему стеку: дашборд Webmaster в Grafana
(`monitoring_search_shows/daily_clicks` с лейблом site=da-dryclean.ru),
контроль индексации — «Индексирование → Страницы в поиске» Вебмастера.

## 6. Известные риски

| Риск | Митигация |
|---|---|
| Doorway-фильтр Яндекса | §3 (уникальность ≥40%, реальные отзывы/время подачи/локальная специфика), поэтапность §5 |
| Каннибализация запросов «москва» без района | Окружные/районные страницы линкуются на городскую, она остаётся канонической по «москва» |
| Утечка веса на 137 страниц | Перелинковка hub&spoke, приоритеты в sitemap (priority + внутренние ссылки с главной на округа) |
| Одинаковые отзывы на разных районах | База отзывов с привязкой «1 отзыв = 1 район», проверка на этапе приёмки |

## 7. Файлы и артефакты на стороне сайта

- Реестр 125 районов + 12 округов с транслитерацией (генерится один раз, версия в git).
- Шаблон гео-страницы + компоненты (блок прайс/CTA «запросить стоимость», форма, FAQ, карта).
- ТЗ копирайтеру на уникальные блоки (пакетами по 15 страниц).
- Регламент уникализации и проверки (антиплагиат ≥ 90% уникального блока).

## 8. Критерии приёмки (этапа 1)

1. 27 страниц (12 округов + 15 районов) открыты для индексации, в sitemap.
2. Каждая страница: уникальный блок ≥ 40%, отзывы привязаны к району без повторов.
3. Разметка валидна (Яндекс.Вебмастер → валидация микроразметки — без ошибок).
4. LCP < 2.5 c (замер на 5 случайных страницах, мобильный профиль).
5. Через 4 недели после запуска: индексация ≥ 90%, рост показов по гео-запросам
   (контроль по данным Вебмастера в Grafana), позиции брендового ядра не упали.
