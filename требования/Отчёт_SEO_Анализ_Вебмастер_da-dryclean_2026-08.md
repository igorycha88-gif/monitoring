## 4. Выявленные проблемы

### П4.1. Слабые сниппеты (CTR 0.6% при позициях 7–8)
Кластер «матрасы»: 1091 показ за 2 недели → 3 клика, все в первую неделю.
Позиции стабильны (7.3), показы растут, клики исчезли — Яндекс показывает сайт,
но сниппет не конкурентен. В выдаче по этим запросам видны конкуренты:
**double-clean, «Диана», klining-pro, tunnel** (их бренды фигурируют в самих
поисковых запросах пользователей — сильный брендовый перехват).

### П4.2. Отсутствие гео-посадочных
Запросы с «москва» (химчистка мягкой мебели на дому **москва**,
химчистка дивана на дому **москва**) показываются с URL `mos-drycleaning.ru/furniture/`
на позициях 11+. Это общая англоязычная страница услуг без гео-специфики.
Районных/окружных посадочных нет вообще. При этом услуга «химчистка на дому» —
максимально локальный бизнес: пользователь ищет исполнителя, который быстро доедет.

### П4.3. «Мёртвая зона» позиций 7–11.5
8 из 8 ключевых запросов в диапазоне 7–11.5. Для входа в топ-3 Яндекса по
коммерческим запросам нужны: полноценные страницы услуг, отзывы,
микроразметка, региональная релевантность (гео-страницы), поведенческие факторы.
Примечание: публикация цен на страницах закрыта ценовой политикой — компенсация
через прайс-лист и CTA «запросить стоимость» (R1.3).

### П4.4. Растущий кластер «диваны» без опоры
Показы по диванам удвоились (+105%) за неделю. Кластер требует усиления
отдельной страницы (сейчас, судя по URL в сниппетах, работает /furniture/).

### П4.5. Зарождающийся кластер «ковры»
Первые 11 показов и 1 клик. Страница услуги «химчистка ковров» нужна заранее —
захватить кластер на старте дешевле, чем догонять.

### П4.6. URL-структура
URL-ы латиницей (/furniture/) без гео-иерархии. Для 125 районных посадочных
требуется плоская, предсказуемая структура с ЧПУ и картой сайта.

## 5. Рекомендации (приоритезированы)

## 6. Прогноз

- Текущий трафик: ~11 кликов/2 недели из поиска.
- После R1 (сниппеты + разметка + CTA-прайс/менеджер): CTR 0.6% → 2% = **~40 кликов/2 нед** без роста позиций.
- После R2 (гео-посадочные) + вход ключевых запросов в топ-5: **300–700 кликов/2 нед**
  (оценка по частотности кластера «матрасы+диваны+мебель на дому» в Москве).
- Точность прогноза низкая (мало истории), контроль — по дашборду Webmaster в Grafana
  (метрики `monitoring_search_daily_clicks/shows`).
