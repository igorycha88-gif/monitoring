# ЧТЗ: Удаление сайтов-заглушек из выпадающих фильтров Grafana

**Версия:** 1.0
**Дата:** 2026-08-24
**Маршрутизация:** Маршрут 3 (инфраструктурная) → исполнитель: **DevOps**
**Тип:** упрощённое ЧТЗ (малая задача, раздел 6 AGENTS.md)

## 1. Проблема

В выпадающих фильтрах «Сайт» дашбордов Grafana (Обзор сайта, Все сайты, Бизнес сайта,
Вебмастер) видны сайты-заглушки `example.com` и `example.org`.

**Корневая причина:** переменные дашбордов — динамические
(`label_values(monitoring_uptime_status, site)` / `label_values(monitoring_search_clicks_total, site)`).
Prometheus на проде содержит 36 устаревших серий с `site=~"example.(com|org)"`
(monitoring_uptime_*, monitoring_ssl_days_left, monitoring_collector_*, ALERTS*).
Сайты давно убраны из `config/sites.yml`, но retention 400d (ADR-008) держит серии
в индексе — `label_values` без временного окна возвращает значения за весь retention.

Admin API Prometheus (`--web.enable-admin-api`) на проде выключен — удалять серии нечем.

## 2. Решение

1. Включить admin API Prometheus: `command: ["--web.enable-admin-api"]` в
   docker-compose.yml (entrypoint уже пробрасывает `"$@"`). Порт 9091 биндится
   только на 127.0.0.1 — наружу не торчит (раздел 0.2 AGENTS.md).
2. На проде удалить серии заглушек и очистить tombstones:
   - `POST /api/v1/admin/tsdb/delete_series` с `match[]={site=~"example\\.(com|org)"}`
   - `POST /api/v1/admin/tsdb/clean_tombstones`
3. Обновить `scripts/verify_prod.py`: убрать `example.com` / `example.org`
   из `EXPECTED_COLLECTORS` (после чистки проверка прод-верификации стала бы падать).
4. Дашборды Grafana НЕ менять — фильтры динамические, очистка данных убирает заглушки.

## 3. Критерии приёмки

1. `GET /api/v1/label/site/values` на проде возвращает только реальные сайты
   (da-dryclean.ru, эвакуация.online; zabor-i-naves.ru — после следующего деплоя).
2. В выпадающих фильтрах всех 4 дашбордов Grafana заглушек нет.
3. Метрики реальных сайтов не затронуты (uptime/ssl/webmaster работают).
4. Существующее приложение на сервере не затронуто (раздел 0.1 AGENTS.md).
5. `scripts/verify_prod.py` не содержит упоминаний example.com/example.org.

## 4. Файлы для изменения

| Файл | Изменение |
|------|-----------|
| `docker-compose.yml` | prometheus: добавить `command: ["--web.enable-admin-api"]` |
| `scripts/verify_prod.py` | убрать example.com/example.org из EXPECTED_COLLECTORS |

## 5. Риски и меры

- **Admin API включён постоянно** — приемлемо: порт только 127.0.0.1, доступ по SSH.
  Оставляем для будущих cleanups (документируется в PRODUCTION.md runbook — вне скоупа).
- **delete_series необратим** — удаляем ТОЛЬКО `match[]={site=~"example\\.(com|org)"}`
  с заранее проверенным списком серий (36 шт., только monitoring_* и ALERTS*).
